# 续跑用提示词模板

把 `NNN` 替换成三位批次号（如 `098`），`N` 替换成不带前导零的批次号（如 `98`），
把整段交给一个子代理执行即可。ROOT 为 `kaoyan-site` 绝对路径。

---

你是考研英语词汇内容专家。请为 20 个考研单词逐个生成「示例级」深度词条解析，并写入指定文件。

【第 1 步】用 read 工具读取输入文件：
`<ROOT>\batches\batch-NNN.json`
其中 words 数组每项含 w（单词）和 t（原始词典释义数组，来自多个来源，可能重复、残缺或略有错误）。

【第 2 步】用 write 工具写入：
`<ROOT>\data\detail\detail-NNN.js`

文件内容必须恰好是（不要 markdown 代码块、不要注释、不要任何额外说明文字）：

```js
window.KY_CHUNKS = window.KY_CHUNKS || {};
window.KY_CHUNKS[N] = { "单词1": {词条对象}, "单词2": {词条对象}, ... };
```

词条对象结构（严格遵守，字段名不可改）：

```json
{
  "origin": "词源流变。例：拉丁语 satio → 古法语 seison，最早意思：合适的时节、时机。",
  "chain": ["引申①：一年里合适的时段 → 季节", "引申②：食物适合调味的时机 → 动词「调味」"],
  "mnemonic": "词源背后的逻辑，1-2 句，说明古人是怎么从本义想到引申义的。",
  "senses": [
    {"pos":"n.","cn":"季节：一年划分出来的时段","examples":[{"en":"the rainy season","zh":"雨季"}]},
    {"pos":"v.","cn":"调味：在恰当时候放佐料","examples":[{"en":"Season the soup.","zh":"给汤调味。"}]}
  ],
  "derived": [{"en":"seasoning","zh":"n. 调料、调味品"}],
  "analogy": "season = “时机”\n大自然的时机 → 季节\n做菜的时机 → 调味",
  "sentences": [
    {"en":"Hotel bookings tend to peak during the holiday season.","zh":"假日期间酒店预订往往会达到高峰。"}
  ]
}
```

【内容要求】

1. senses 必须覆盖该词在考研中所有常考词性和义项；原始释义 t 不全或明显有误时，由你补充完整、修正。每个词性可给多个 sense 对象。
2. cn 字段格式为「义项：通俗解释」。examples 给 1-3 个典型搭配或短句，必须配中文。
3. origin 必须是真实的词源（拉丁语/希腊语/古法语/古英语等），写出演变路径。确实查不到可靠词源的词，写构词分析（前缀+词根+后缀）并说明，绝不编造词源。
4. chain 给 2-4 条引申链，每条以「引申①」「引申②」…开头，用「→」表示推导。
5. mnemonic 解释本义如何过渡到引申义。若该词没有可讲的词源逻辑，写空字符串 ""。
6. analogy 是易记类比，可用 `\n` 换行。
7. sentences 给 3 条完整例句，考研/学术/报刊风格，长度 12-25 词，**每条必须是 `{"en":"...","zh":"..."}` 对象并配准确中文翻译**；句子要尽量体现该词不同义项或搭配。
8. derived 给常见衍生词（没有就给空数组 []）。
9. 中文用简体中文和中文标点；词性标记统一用 n. / v. / adj. / adv. / prep. / conj. / pron. / num. / int.。
10. 对象必须包含输入里的全部 20 个词，key 与输入 w 字段完全一致（大小写、标点都要一致）。
11. 字符串里如果出现双引号，必须转义为 `\"`；换行必须写成 `\n`；确保 `window.KY_CHUNKS[N]` 的右值能通过 `JSON.parse`。

【第 3 步】写完后只回复一行：`DONE NNN 20`
